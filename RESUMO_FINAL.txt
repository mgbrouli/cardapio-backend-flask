🎯 DESIGN PATTERNS APLICADOS:

✓ Repository Pattern
  - Abstração de acesso a dados
  - CRUD genérico + métodos específicos
  - Facilita testes e mudanças no banco

✓ Service Layer
  - Centraliza lógica de negócio
  - Orquestra múltiplos repositórios
  - Retorna estrutura de resposta padrão

✓ Blueprint Pattern
  - Rotas organizadas por funcionalidade
  - Públicas, Autenticação, Produtos, Empresa
  - Fácil de escalar

✓ Factory Pattern
  - create_app() para criar aplicação
  - Configurações flexíveis
  - Suporta desenvolvimento/produção/testes

🚀 COMO USAR A NOVA ESTRUTURA:

1. ROTAS PÚBLICAS:
   └─ GET /                       → Landing page
   └─ GET /<empresa_id>           → Visualizar cardápio

2. AUTENTICAÇÃO:
   └─ POST /cadastro              → Registrar novo usuário
   └─ POST /login                 → Fazer login
   └─ GET /logout                 → Fazer logout

3. GERENCIAR PRODUTOS (Autenticado):
   └─ POST /produto/add/<empresa_id>        → Adicionar
   └─ POST /produto/edit/<produto_id>       → Editar
   └─ DELETE /produto/delete/<produto_id>   → Deletar

4. CONFIGURAÇÕES (Autenticado):
   └─ GET /empresa/home           → Dashboard
   └─ GET /empresa/config/<id>    → Configurações
   └─ POST /empresa/config/<id>   → Atualizar

💻 EXEMPLOS PRÁTICOS:

Exemplo 1: Criar Produto
────────────────────────
from app.services.produto_service import ProdutoService

service = ProdutoService()
resultado = service.criar_produto(
    empresa_id=1,
    nome="Pizza",
    ingredientes="Queijo",
    preco=35.00
)

if resultado['success']:
    print(f"Produto criado: {resultado['produto_id']}")


Exemplo 2: Listar Produtos
──────────────────────────
from app.services.produto_service import ProdutoService

service = ProdutoService()
produtos = service.obter_produtos_com_imagens(empresa_id=1)

for item in produtos:
    print(f"{item['produto'].nome} - R$ {item['produto'].preco}")


Exemplo 3: Autenticar
────────────────────
from app.services.auth_service import AuthService

🔄 FLUXO DE DESENVOLVIMENTO:

1. Cliente envia requisição
         ↓
2. Route recebe e valida entrada
         ↓
3. Service aplica lógica de negócio
         ↓
4. Repository executa operação no BD
         ↓
5. Service retorna resultado estruturado
         ↓
6. Route renderiza resposta
         ↓
7. Cliente recebe resposta
